# 🚀 Featured Projects

## 🩺 Skin Disease Classification Using Deep Learning

A deep learning-based image classification system that classifies skin disease images into **4 categories** using transfer learning.

### 🔹 Key Highlights

- Classified **7,602 skin images**
- Used **MobileNetV2** pretrained on ImageNet
- Applied **Transfer Learning**
- Input resolution: **224 × 224 × 3**
- Used **Global Average Pooling, Dense Layer, ReLU, Dropout and Softmax**
- Compared **Adam, SGD and RMSprop**
- Best validation accuracy: **84.27%**
- Built an interactive interface using **Gradio**

### 🛠️ Technologies

`Python` `TensorFlow` `Keras` `MobileNetV2` `OpenCV` `NumPy` `Scikit-learn` `Gradio`

## 🤖 YouMatter — AI-Powered Mental Health Companion

A **Generative AI-powered conversational application** designed to provide a warm, supportive and safety-focused conversational experience.

### 🔹 Key Highlights

- Built using **FastAPI and LLM integration**
- Supports **English, Hindi and Hinglish**
- Uses contextual conversation information
- Implements a **multi-layer safety pipeline**
- Performs safety/risk classification before generating responses
- Handles **distress, crisis and severe-risk situations**
- Supports **guardian consent and alert mechanisms**
- Includes **rate limiting and API resilience**
- Uses asynchronous processing for improved responsiveness
